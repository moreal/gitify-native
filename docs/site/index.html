A familiar Mac install

From download to menu bar in a minute

  1. 1
    Download

    Get the latest Gitify.dmg from GitHub Releases.

  2. 2
    Drag

    Move Gitify into the Applications shortcut in the disk image.

  3. 3
    Launch

    Open Gitify, sign in, and find it in your menu bar from then on.
